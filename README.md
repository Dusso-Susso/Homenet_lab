# HomeNet Lab — Engenharia de TI & Cybersecurity

Laboratório prático para construir progressivamente uma infraestrutura empresarial de teste e aprender redes, Linux, desenvolvimento, operações e segurança por meio de missões e troubleshooting.

## Situação inicial

Estrutura organizada em 10/11/2026. O Windows será o ponto de partida para o trabalho local. A separação entre máquinas e o processo de implantação serão discutidos posteriormente.

As pastas organizam documentação, código e configurações. Sua existência não significa que serviços ou controles estejam implementados. O inventário e os registros serão preenchidos com evidências do laboratório.

## Registro do progresso

- **Planejado:** proposta ou tarefa ainda não executada.
- **Implementado:** alteração aplicada; a validação pode estar pendente.
- **Validado:** resultado verificado por teste, com data e evidência.

Decisões aceitas e implementações validadas devem ser distinguidas. Informações ausentes permanecem como pendências, sem presumir resultados.

Não versionar senhas, tokens, chaves privadas, discos de VM ou dados pessoais. Revisar os arquivos antes de cada commit; o .gitignore não substitui essa revisão.
