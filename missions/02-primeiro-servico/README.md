# Missão 02 — Primeiro serviço

Objetivo: documentar o primeiro serviço HTTP e suas condições de disponibilidade. Pré-requisitos: identificar servidor, rede e conteúdo servido. Critério de conclusão: registrar execução, endereço, porta, teste de acesso e comportamento ao encerrar processo ou sessão. Estado documental: pendente de consolidação; não presumir persistência sem teste.
